# 電商營運計算助手

原生 HTML、CSS、JavaScript 製作的手機優先 PWA，提供九項營運試算、公式與數字代入、本機記憶、方案比較及離線使用。

## 本機預覽

執行 `node serve.mjs` 後開啟 `http://127.0.0.1:4173`。Service Worker 必須透過 `localhost` 或 HTTPS 使用。

## GitHub Pages

將本目錄內容放到儲存庫根目錄，並在 GitHub Pages 選擇由分支部署。所有資源皆採相對路徑，可支援專案子路徑。

公開網站：https://jyyounz-lab.github.io/ecommerce-operations-helper/
